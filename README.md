# Petverse

Hatch, raise and battle your own 3D pet. Web3 game on Robinhood Chain.

- `src/` – Next.js app (react-three-fiber pets, game screens)
- `chain/` – smart contracts (Hardhat)
- `/gallery` – every species, baby and adult

## Run

```bash
npm install
npm run dev   # http://localhost:3000
```
